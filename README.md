# MindTrauma AI

AI-assisted real-time stress and trauma screening and support platform developed for Smart India Hackathon 2026.

## Problem Statement

**SIH26093 – AI-Based Real-Time Stress and Trauma Assessment Module for Victims/Complainants Accessing NHAA (14566) and Integrated Portal**

## Technologies Used

- React
- TypeScript
- Node.js
- Gemini API
- HTML/CSS
- Git & GitHub

## AI-Assisted Development Tools

- Google AI Studio
- Google Antigravity

## Key Features

- Trauma-sensitive screening
- AI-assisted support through Aasra
- Stress and wellbeing assessment
- Daily mood check-ins
- Weekly mood tracking
- Support resources
- Chat history
- User consent and privacy-focused design

## Development

This project was developed with AI-assisted tools. The team was responsible for the problem analysis, solution design, feature decisions, testing, integration, and final implementation.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
