# MindTrauma Screener

Validated clinical PTSD screening, DSM-5 trauma psychoeducation, and compassionate AI support.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
